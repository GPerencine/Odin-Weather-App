# Weather App

This project is part of the JavaScript course from **The Odin Project**. In this project, I built a browser-based weather application using HTML, CSS, and JavaScript, allowing users to search for weather information by location and switch between Fahrenheit and Celsius.

## Preview

![Weather App Preview](./images/preview.png)

By completing this project, I demonstrated an understanding of asynchronous JavaScript, API integration, Promises, async/await, JSON data processing, DOM manipulation, event handling, dynamic content rendering, and modular code organization. I also gained experience working with external APIs and handling asynchronous data in an interactive web application.

This project marked an important step in working with external services and asynchronous JavaScript, strengthening my ability to build applications that retrieve, process, and display real-world data dynamically.
